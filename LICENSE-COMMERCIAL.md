# Commercial Licensing — Patenter

This skill is licensed under **Apache License 2.0 with Commons Clause v1.0**.
In short: use and modify freely, but **selling** requires permission.

## What counts as "Sell" (needs a license)?

- Selling the skill itself or a modified version
- Paid hosted service / API based on it (even modified)
- Paid patent-search, FTO, landscape, or report services whose value
  comes substantially from this skill
- Consulting / support packages sold around it
- Bundling it into a product you sell (including training courses)

## What is free (no license needed)?

- Personal learning, self-study, academic research
- Internal evaluation and non-commercial use
- Contributions back to this repo

## How to get a commercial license

1. Email **vitolai@gmail.com** with subject `[Commercial License] Patenter`
2. Include: name / company, intended use (service / resale / SaaS / OEM),
   estimated users or seats, whether you need redistribution rights
3. You will receive a quote + a signed commercial license file
4. Keep the license file with your deployment as proof
